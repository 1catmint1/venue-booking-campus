# 北理场馆预约 v1.3.0 本地创新版

面向校园课余运动、周期社团训练与场馆日常服务。核心是公平候补、按学生/教工/校外与时段计价、混杂历史中的个性化推荐，以及有范围和有效期的十二角色协作。基础预约和候补不出售优先权。

界面修订6已通过用户验收。当前是明确标注的模拟服务，不是学校官方预约系统。源码公开不代表应用市场上架或兼容认证。

## 本地运行

使用Node.js 18+，在源码根运行 node server/server.cjs，打开 http://127.0.0.1:18843/ 。SQLite数据保存在work/server-data，不连接学校或真实支付。浏览器版本需要业务服务，不能按纯静态站发布。

Python3可执行，或用VENUE_TEST_PYTHON指定已有解释器后，运行 node --test --test-concurrency=1 review-tools/worker-review.test.cjs review-tools/review-assets.test.cjs 。冻结导出源码本轮10项测试通过，结果与版本清单分别保存。真实接口、v1.3真机及公网万人验证待完成，千人结果只属于独立共享事务测试内核。

原生工程需相符的DevEco Studio/SDK和自己的有效签名。导出不含个人签名、密钥、真实证明照片或运行用户库。此次原生重建受到CPU保护中止，交付不提供过期HAP冒充新版。Windows候选包另见交付清单，未自动升级旧安装或公网链接。
